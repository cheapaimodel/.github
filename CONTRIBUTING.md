# Contributing to CheapAIModel

Thanks for helping out! These guidelines apply to every repository in the CheapAIModel organization.

## Reporting bugs

Open an issue in the relevant repository and include:

- What you did (code snippet or request)
- What you expected
- What happened instead (error message, status code)
- SDK / language version

**Never paste your API key** into an issue.

## Pull requests

1. Fork the repo and create a branch from `main`.
2. Keep changes focused — one fix or feature per PR.
3. Add or update examples and docs if behavior changes.
4. Make sure existing tests and examples still run.

## Questions

For usage questions, open a GitHub Discussion or contact us through the website.
